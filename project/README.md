## 🛤️ Three Tracks

| Track | Focus | Example |
|-------|-------|---------|
| **Track A** | Optimization | Resource allocation, scheduling, portfolio construction |
| **Track B** | Analytics + Insights | Analysis tools, recommendation engines, prediction → action |
| **Track C** | Decision Intelligence | User profiling → personalized recommendations |

---

## 📦 Deliverables

1. **GitHub Repository** — Code + stellar README
2. **Deployed App** — Working Streamlit on the web
3. **Demo Video** — 3-5 minute Loom walkthrough

---

## ⚖️ The 70/30 Philosophy

| 70% Thinking | 30% Building |
|--------------|--------------|
| Problem identification | Working prototype |
| Value proposition | Streamlit deployment |
| Analytics approach | Core functionality |
| User journey design | Cursor handles the code |

## 🚀 Quick Start

1. **Choose your track** (A, B, or C)
2. **Fork the template:** [portfolio-optimizer](https://github.com/harslan/portfolio-optimizer)
3. **Lock your concept** by Dec 6
4. **Build with Cursor** — let AI do the heavy lifting
5. **Deploy to Streamlit Cloud**
6. **Record your Loom video**
7. **Submit via Canvas**
